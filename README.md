# Cotham Tigers corner playbook

A self-contained, mobile-friendly animated coaching board.

- A — Attack: one arm overhead.
- B — Bounce Shot: both arms overhead.
- C — Bounce Cross: forearms crossed overhead.
- D — Back Door: hand on head.

Open index.html locally or visit https://dickymoore.github.io/cotham-tigers-corners/ .

Edit index.html and push to main. GitHub Pages publishes from the repository root. No build, external assets or backend are required.

The choreography and playback timing are illustrative and need rehearsal on grass. Roles are generic. Defenders and finishes are examples rather than guaranteed outcomes.
